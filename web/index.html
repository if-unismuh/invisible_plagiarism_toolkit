Invisible Plagiarism Toolkit

Unggah dokumen Word dan laporan Turnitin untuk diproses dengan teknik anti-deteksi. Sistem akan mengekstrak highlight, menerapkan manipulasi selektif, lalu menyediakan hasil akhir beserta laporan lengkap.

Processing Mode

File yang diunggah akan ditempatkan di workspace/input/original dan workspace/input/turnitin sebelum pipeline CLI dijalankan.
